# Тренажёр по компьютерным сетям

[Открыть тренажёр](https://nikeka-git.github.io/network-quiz/)

Четыре варианта, 85 вопросов на английском и пояснения на русском. Тренажёр проверяет 77 вопросов с одним или несколькими правильными ответами. У 8 вопросов в исходном документе отсутствует часть вариантов или надёжный ключ, поэтому они доступны для разбора без оценки. Материалы восстановлены по фотографиям прошлых экзаменов.

Режим «Разбор ошибок» показывает вопросы текущего варианта, на которые ты ответил неверно. После верного ответа вопрос убирается из списка ошибок. Прогресс хранится в браузере.

Для запуска локально открой `index.html`. Сайт не требует установки зависимостей и сборки. GitHub Pages публикует его из корня ветки `main`.
