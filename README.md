# Тренажёр по компьютерным сетям

[Открыть тренажёр](https://nikeka-git.github.io/network-quiz/)

23 вопроса на английском с пояснениями на русском из документа `Computer_Networks_Photo_Verified_Correction.docx`. В тренировке доступны варианты 1, 2 и 4. В приложении собраны фотографии всех четырёх вариантов, включая вариант 3.

Режим «Разбор ошибок» показывает вопросы текущего варианта, на которые ты ответил неверно. После верного ответа вопрос убирается из списка ошибок. Прогресс по проверенному набору хранится в браузере отдельно от предыдущей версии.

Для запуска локально открой `index.html`. Сайт не требует установки зависимостей и сборки. GitHub Pages публикует его из корня ветки `main`.
