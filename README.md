# Тренажёр по компьютерным сетям

[Открыть тренажёр](https://nikeka-git.github.io/network-quiz/)

86 вопросов на английском с пояснениями на русском из фотографий четырёх вариантов. Метка «Восстановлено по контексту» означает, что часть формулировки или вариантов ответа восстановлена по видимому тексту. В 14 карточках есть такие фрагменты. Ещё 14 вопросов целиком остались за краем кадра и пропущены. Фотографии доступны в приложении к тренажёру.

Режим «Разбор ошибок» показывает вопросы текущего варианта, на которые ты ответил неверно. После верного ответа вопрос убирается из списка ошибок. Прогресс хранится в браузере. Из предыдущей версии переносятся результаты вопросов с теми же вариантами и ключами.

Для запуска локально открой `index.html`. Сайт не требует установки зависимостей и сборки. GitHub Pages публикует его из корня ветки `main`.
